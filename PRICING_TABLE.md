# Marketplace Pricing Table — Attachment Checkout for Confluence

**Payment Model:** Paid via Atlassian (Cloud Monthly & Annual Progressive Per-User Tiers)

| User Tier | Monthly Rate | Notes |
|---|---|---|
| **Up to 10 users** | **\$10.00 / month flat** | Starter flat rate for teams up to 10 users |
| **1–100 users** | **\$2.50 / user / month** | Progressive per-user tier |
| **101–250 users** | **\$1.50 / user / month** | Progressive per-user tier |
| **251–1,000 users** | **\$1.00 / user / month** | Progressive per-user tier |
| **1,001–2,500 users** | **\$0.50 / user / month** | Progressive per-user tier |
| **2,501–5,000 users** | **\$0.25 / user / month** | Progressive per-user tier |
| **5,001–10,000 users** | **\$0.15 / user / month** | Progressive per-user tier |
| **10,001+ users** | **\$0.10 / user / month** | Enterprise progressive tier |

## Example Monthly Totals (Progressive Tier Calculation)
- **10 users:** \$10.00 / month
- **50 users:** \$125.00 / month (`50 × $2.50`)
- **250 users:** \$475.00 / month (`100 × $2.50 + 150 × $1.50`)
- **1,000 users:** \$1,225.00 / month (`$475 + 750 × $1.00`)
